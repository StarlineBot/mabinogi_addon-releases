# 섯다라인 마비노기 애드온

마비노기 화면을 **실시간으로 읽어** 버프·디버프 남은 시간과 각종 정보를 게임 위에
오버레이로 보여주는 Windows 상주 프로그램입니다.

[![최신 버전](https://img.shields.io/github/v/release/StarlineBot/mabinogi_addon-releases?label=%EC%B5%9C%EC%8B%A0%20%EB%B2%84%EC%A0%84&color=00B894)](https://github.com/StarlineBot/mabinogi_addon-releases/releases/latest)

### ⬇️ 내려받기

👉 **[최신 버전 내려받기](https://github.com/StarlineBot/mabinogi_addon-releases/releases/latest)** (`mabinogi-addon-vX.Y.Z.exe`)

> 설치 없이 **exe 하나만 받아 실행**하면 됩니다. 실행하면 관리자 권한 요청(UAC) 창이
> 한 번 뜨는데, 게임이 관리자 권한으로 돌아가기 때문에 **오버레이가 게임 위에 보이려면
> 꼭 "예"** 를 눌러야 합니다.
>
> 처음 실행 시 **"Windows의 PC 보호(SmartScreen)"** 경고가 뜰 수 있습니다. 서명되지 않은
> 개인 배포라서 그런 것이며, **추가 정보 → 실행**을 누르면 됩니다.

## ✨ 주요 기능

### 🟢 버프 트래커
상태목록창에서 등록한 버프를 찾아 **남은 시간**을 읽고, 지정한 위치에 가로로 나열합니다.
연장이 필요한 시점(기본 30초)에 **소리·점멸**로 알려줍니다.
<!-- <img src="docs/screenshot-buff.png" alt="버프 오버레이" width="520"> -->

### 🔴 디버프 트래커
보스 체력바 위 디버프 줄을 읽어, **아직 걸리지 않은 디버프만** 오버레이로 보여줍니다.
(= 지금 걸어야 할 디버프를 한눈에)

### ⏳ 투아림 진행도
투아림 관련 진행도(%)를 읽어 표시합니다.

### 🪞 커스텀 오버레이 (화면 거울)
게임 화면의 특정 영역을 **다른 위치에 실시간으로 복제**해 띄웁니다.
DWM 썸네일 방식이라 **CPU 사용량이 거의 0%** 입니다.

### 🔔 음성 알림 (보이스팩)
버프 연장·디버프·투아림 알림을 **음성**으로 받습니다. 성격별 말투를 고를 수 있고,
설정에서 **미리듣기**와 **즉시 전환**이 됩니다.

### 🧑‍🤝‍🧑 파티 모집 알림 / 📝 메모
파티 모집 알림, 게임 위에 상시 띄우는 메모 오버레이를 제공합니다.

### ⚙️ 편의 기능
- **Windows 시작 시 자동 실행** (관리자 권한 유지)
- **자동 업데이트** (새 버전 감지 → 한 번에 교체)
- **설정 백업/복원(zip)** 과 **초기화**

## 🔒 안전성 — 화면을 "읽기만" 합니다

- **키 입력·클릭 자동화를 하지 않습니다.**
- **게임 메모리를 읽지 않습니다.**
- 오직 **화면(스크린샷)만 분석**해 정보를 보여줍니다.

> 매크로·오토가 아니라 "화면을 대신 봐 주는 보조 도구"입니다.
